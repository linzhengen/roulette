ルーレットアプリ

このルーレットアプリはVue.js 3とReact.jsの両方で実装されています。選択肢を追加してルーレットを回しましょう！

選択肢はブラウザのローカルストレージに保存されます。

Vue.js バージョン

Vue.js 3 Composition APIで実装

Vue.js 3の最新機能を利用したモダンな実装です。

Vue.js ルーレットを開く

React バージョン

React 18 Hooksで実装

React Hooksを使用した関数コンポーネントでの実装です。

React ルーレットを開く

機能

  • 選択肢の追加・削除
  • 選択肢の重み付け（確率調整）
  • ルーレットの回転アニメーション
  • 当選結果の表示
  • ローカルストレージによるデータ永続化
